
# QA Portfolio — Practice Software Testing

## About the Project

This repository documents hands-on software testing activities performed on the Practice Software Testing web application.

The goal is to develop practical QA skills through exploratory testing, functional test design, defect reporting, regression testing, and API testing.

## Project Scope

- Exploratory testing of the product catalog
- Functional testing of filters and sorting
- Test case design and execution
- Bug reporting with reproducible steps
- Regression testing
- API testing and validation
- Test evidence and documentation

## Application Under Test

Practice Software Testing  
https://practicesoftwaretesting.com/

## Testing Approach

Testing activities focus on identifying unexpected behavior, validating expected results, documenting reproducible defects, and assessing the impact of failures.

Test results are recorded based on actual observations. Unexecuted tests are not marked as passed.
